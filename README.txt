SAFEHOME-X SISTEMAS — SITE INSTITUCIONAL V2

Estrutura:
- index.html
- style.css
- script.js
- assets/logo-safehome-x.png

Como editar:
1. Abra a pasta no VS Code.
2. Textos e seções: index.html
3. Cores, layout e responsividade: style.css
4. Interações: script.js
5. Troque ou adicione imagens em assets/

Para trocar uma imagem, mantenha o novo arquivo dentro de assets/ e altere o caminho no HTML.

Publicação:
Este é um site estático (HTML/CSS/JS). Ele pode ser publicado em serviços como GitHub Pages, Cloudflare Pages, Netlify ou uma hospedagem tradicional.
Depois de publicar, você pode apontar um domínio próprio para o site.

Observação:
- Os preços estão como "Preço em definição" porque os valores comerciais oficiais não foram informados.
- Contatos e endereço refletem os dados fornecidos para a versão atual.
- A seção "Projeto em desenvolvimento" é intencional para não apresentar recursos ainda não finalizados como produto comercial concluído.
